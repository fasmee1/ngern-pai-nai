# สถานะโปรเจกต์ "เงินไปไหน"

อัปเดตล่าสุด: 7 พฤศจิกายน 2569 (2026-11-07)

## เสร็จแล้ว

- โครงโปรเจกต์ Next.js 16 + TypeScript + Tailwind และหน้าตาตาม DESIGN.md
- เข้าระบบด้วย Google ผ่าน Supabase (ทดสอบแล้วโดยคุณฟัซมี)
- จดรายการรับ/จ่าย แก้ไข และลบ พร้อมกดย้อนกลับได้ทันที
- หน้าสรุป: ประโยคสรุป กราฟวงกลมแยกหมวด รายรับ รายจ่าย คงเหลือ
- ตั้งงบรายหมวด และแจ้งแบบใจดีเมื่อใช้เกินงบ
- บัญชี: ออกจากระบบ และลบบัญชีพร้อมข้อมูลทั้งหมด (ต้องพิมพ์คำว่า "ลบ" เพื่อยืนยัน)
- หน้านโยบายความเป็นส่วนตัว (ฉบับร่าง ควรให้ผู้รู้ด้านกฎหมายตรวจก่อนเปิดกว้าง)
- ติดตั้งลงหน้าจอมือถือได้ (manifest + ไอคอน)
- ตรวจข้อมูลที่รับจากผู้ใช้ด้วยเทสต์ 5 ข้อ และตรวจโค้ด lint/typecheck ผ่าน

## ยังต้องทำ

1. **รันไฟล์ฐานข้อมูล** `supabase/migrations/0001_init.sql` ใน SQL Editor ของ Supabase
   (ต้องทำก่อนใช้งาน ไม่อย่างนั้นข้อมูลจะบันทึกไม่ได้)
2. **นำขึ้นออนไลน์** ที่ Vercel ต้องใช้บัญชี Vercel ของเจ้าของระบบ และใส่ค่า URL กับ publishable key เหมือนใน `.env.local`
3. **เพิ่มโดเมนจริง** ใน Supabase > URL Configuration และใน Google Cloud (Authorized redirect URI ยังเป็น supabase callback เดิม)
4. **ตรวจกฎเรื่อง PDPA** กับผู้รู้ด้านกฎหมาย และแก้นโยบายให้เหมาะกับการเปิดให้คนทั่วไปใช้
5. **ตอนเปิดใช้จริง** ควรออกจากโหมดทดสอบของ Google (Publish app) หลังทำ Branding ให้ครบ
